# How to Download the Transformer Course PDFs

The **Save button inside Cursor's PDF preview often does not work**. That is a viewer limitation, not a broken file.

Use one of these methods instead:

## Method 1 — Download the ZIP (easiest)

Download this file from the workspace:

`transformer-course/Transformer_Course_All_PDFs.zip`

Contains:
- `Transformer_Complete_Course_Attention_Is_All_You_Need.pdf` (full course, Parts 0–20)
- `Attention_Is_All_You_Need_Vaswani_2017.pdf` (original paper)
- `Part0_How_To_Read_Attention_Is_All_You_Need.pdf` (Part 0 only)

## Method 2 — From the Cursor file tree

1. Open the **Files** panel (left sidebar).
2. Go to `transformer-course/`.
3. **Right-click** `Transformer_Complete_Course_Attention_Is_All_You_Need.pdf`.
4. Choose **Download** (not the Save icon in the PDF preview).

## Method 3 — From the chat link

1. **Right-click** the PDF link in the agent message.
2. Choose **Save link as…** / **Download linked file**.
3. Do **not** open the preview first and use its Save button.

## Method 4 — From git (branch)

Files are on branch `cursor/transformer-detailed-course-pdf-fc84`:

```
transformer-course/Transformer_Complete_Course_Attention_Is_All_You_Need.pdf
```

Clone or download that branch from your repository.

## If nothing works

Reply in the chat and ask to email or attach via another method. The PDF itself is valid (45 pages, ~95 KB).
